# Hospitals

A collection of premium healthcare, clinic, and hospital website templates.

## Folders
- [`/hospital`](./hospital) - Curevo Hospital & Healthcare Website (Fully responsive, interactive appointments, case studies, treatments, and doctors).
- [`/hospital1`](./hospital1) - Hero Hospital Website (Centers of excellence, doctors directory, patient facilities, interactive appointments, and customized Regortz attribution).
- [`/hospital2`](./hospital2) - Orynth Medical Faculty & Research Sanctuary (Ultra-luxury hospital & physician sanctuary website featuring cinematic video hero, 3D tilt cards, interactive faculty & suites, responsive mobile navigation, and Regortz agency credit).
